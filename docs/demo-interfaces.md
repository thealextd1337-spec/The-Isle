# Demo: verbindliche Schnittstellen

Unity 6000.6.4f1, URP 17.6, Input System. Projekt unter `Game/`. Namespace `TheIsle`. XZ-Flugebene, +Z Bug, +X Steuerbord, Y=0 Simulation; Ebenen wechseln als diskrete Regionen. Root baut 3D-Darstellung um diese Simulation und Kamera isometrisch. Keine anderen offenen Unity-Projekte ändern. Keine manuelle Scene/Prefab/Settings-YAML. Root importiert Metadaten und erstellt Szene mit Editor API. Keine zusätzlichen Pakete.

## Kamera und Pausenverhalten

`FlightCameraRig` folgt dem Spieler mit geschwindigkeitsabhängigem Vorblick, ruhigem Hafenfokus und gemeinsamer Kampfübersicht. `Automatic`, `FocusPoint`, `ResetView()` und `SetManualZoom(float)` bilden die öffentliche Schnittstelle. C setzt die Automatik zurück, Z/X drehen die Ansicht, +/− und Mausrad wählen einen dauerhaft manuellen Zoom. Schiffskurs wird ausschließlich über WASD/Pfeile gesetzt; kein Maussteuern.

`ShipMotor.AngularSpeedDegrees` zeigt die physische Drehrate. Begrenztes Drehmoment folgt einer vom Tastaturruder angeforderten Drehrate, ohne Zielkurs-Autopilot. Loslassen dämpft die Rotation, Gegensteuern kehrt sie um, Leertaste bremst Translation und Drehung.

`DemoHud.ToggleHelp()` pausiert Simulation und Audio. Schließen und Szenen-Neustart stellen den vorigen Zustand wieder her. Während der Pause sind Salven und E-Interaktionen gesperrt.
